# Frontend ESTIAM - Structure du dépôt

## Structure du dépôt

```
COURS_FrontEnd/
│
├── [app-estiam-front/](app-estiam-front/)  
│   └── Application d'exemples de composants React (Bonjour, Bouton, Formulaire, Listes, etc.)
│
├── [app-gestion-contact/](app-gestion-contact/)  
│   └── Application de gestion de contacts (ajout, modification, suppression, recherche de contacts)
│
├── [app-todoapp/](app-todoapp/)  
│   └── Application de gestion de tâches (ajout, suppression, affichage de todo)
│
```

## Détail des applications

### [app-estiam-front](app-estiam-front/)
Application de démonstration de composants React de base (titres, listes, formulaires, gestion d'événements, etc.).

### [app-gestion-contact](app-gestion-contact/)
Application pour gérer une liste de contacts :
- Ajouter un contact
- Modifier un contact
- Supprimer un contact
- Rechercher un contact

### [app-todoapp](app-todoapp/)
Application simple de gestion de tâches (todo list) :
- Ajouter une tâche
- Supprimer une tâche
- Afficher la liste des tâches
